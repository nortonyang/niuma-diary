# AI 辅助开发工作流 (AI Workflow)

本目录用于存放与 AI（如 Gemini, Codex）协作开发相关的工作流定义、自动化脚本及指令规范。

## 目录结构

- `README.md`: 本说明文件。
- `prompts/`: (建议) 存放常用的 Prompt 模板。
- `scripts/`: (建议) 存放辅助 AI 执行任务的本地脚本。
- `configs/`: (建议) 存放 AI 工具的配置信息。

## 协作模式

建议参考 `docs/ai-workflow/future-development-requirements.md` 进行需求驱动开发。
