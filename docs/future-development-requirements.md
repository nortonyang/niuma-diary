## 1. 开发目标

当前版本已经完成 MVP 主链路。后续开发目标不是继续堆功能，而是先把“能稳定上线、用户敢用、愿意复用、愿意分享”做好。

核心目标：

1. 上线稳定：真机使用、云同步、分享卡、隐私合规不能有明显断点。
2. 日常留存：用户每天 30 秒能完成记录，并能从日历/复盘中看到反馈。
3. 分享传播：指数卡和赚钱卡稳定生成，文案有记忆点，但不暴露隐私。
4. 离职准备：把“想走”的情绪引导到“先记录、先准备、再决定”。
5. 技术可维护：拆分首页和分享卡大文件，为后续报告、主题、同步策略留空间。

### REQ-1004 节假日与倒计时正确性

优先级：P0  
涉及文件：`pages/today/today.js`

背景：

首页最近假期是高频展示信息，如果劳动节过完仍展示五一，会直接影响可信度。

功能需求：

- 当前日期之后展示最近一个法定假期。
- 假期期间显示“进行中”。
- 假期结束后自动切到下一个假期。
- 没有配置下一假期时，至少回退到春节倒计时。

测试用例：

- 2026-05-06：展示端午节，目标日期 2026-06-19。
- 2026-06-19：展示端午节进行中。
- 2026-06-22：展示中秋节。
- 2026-10-08：展示 2027 元旦或春节，不能展示已过国庆。

后续技术要求：

- v1.1 或 v1.2 将节假日数据拆到 `utils/holidays.js`。
- 每年节假日安排公布后单独更新配置。

### REQ-1101 首页保存流程优化

优先级：P1  
涉及页面：`pages/today`

现状：

保存记录后会重新加载首页，并可能触发云同步再刷新。

功能需求：

- 点击保存后，立即更新当前页面 UI。
- 本地保存成功后展示“已保存本机”。
- 云同步开始展示“云端同步中”。
- 云同步成功展示“云端已同步”。
- 云同步失败展示“云同步失败，已保存在本机”。
- 不因为云同步结果整页重载。

验收标准：

- 点击保存后滑杆、心情、原因、吐槽内容不闪动。
- 弱网下用户不会丢失刚输入内容。
- 失败后再次进入页面仍能看到本地记录。

### REQ-1102 吐槽输入草稿防抖

涉及页面：`pages/today`

验收标准：

- 快速输入 30 个字不会造成明显卡顿。
- 输入后立刻切走再回来，草稿仍保留。
- 正式保存后不再恢复旧草稿。

验收标准：

- 本地存储增加 `schemaVersion`。
- App 启动时执行 migration。
- migration 必须幂等，多次运行不破坏数据。
- 老数据缺字段时补默认值。

建议结构：

```js
{
  schemaVersion: 1,
  migratedAt: 1778774400000
}
```

验收标准：

- 老用户升级后数据仍能读取。
- 清空数据后 schema 能重新初始化。
- migration 失败时不清空用户数据。

### REQ-1202 云同步冲突策略

优先级：P1  
涉及文件：`utils/cloud-data.js`、`utils/storage.js`

功能需求：

- 每条数据都有 `updatedAt`。
- 本地和云端同一记录冲突时：
  - `updatedAt` 新的一方胜出。
  - 如果都更新且无法判断，保留本地并记录冲突。
- 设置类数据按字段合并。
- 列表类数据按 `id` 合并。

验收标准：

- 离线修改愿望后，再联网不会被旧云端覆盖。
- 两台设备修改不同愿望时能合并。
- 同一条愿望冲突时不会静默丢失本地修改。

### REQ-1203 待同步队列

优先级：P1  
涉及文件：`utils/storage.js`、`utils/cloud-data.js`

功能需求：

- 云同步失败时记录 pending 操作。
- pending 操作包含：
  - 操作类型：create/update/delete。
  - 集合名。
  - 本地 id 或 recordDate。
  - payload。
  - retryCount。
  - lastError。
  - createdAt。
- App 启动、页面 onShow、手动重试时尝试同步。
- 超过最大重试次数后保留并提示。

验收标准：

- 断网新增愿望，联网后可自动同步。
- 断网删除清单，联网后云端也删除。
- 同步失败不会导致本地数据消失。

### REQ-1204 云端清空数据

优先级：P1  
涉及页面：`pages/me`  
涉及文件：`utils/cloud-data.js`

功能需求：

- “清空本机数据”只清本地。
- “清空云端数据”删除当前用户所有云端记录。
- 清空云端前二次确认。
- 清空云端成功后同步清本地，或提示用户是否保留本地。

验收标准：

- 用户能明确选择只清本机还是清云端。
- 清空云端后换设备不会恢复旧数据。
- 云端清空失败时本地不被误删。

## 12. 全局验收标准

### 功能稳定

- 首页可完成 30 秒打卡。
- 日历能展示历史记录。
- 愿望可新增、编辑、删除。
- 清单可勾选、新增、删除。
- 分享卡可保存。
- 我的页可设置月薪和工作日。

- 默认分享图不展示月薪。
- 默认分享图不展示吐槽原文。
- 云数据库不是公开读写。
- 清空数据前有二次确认。
- 导出数据前有敏感信息提醒。

### 断网可用

- 断网可打开首页。
- 断网可保存本地记录。
- 断网可查看本地日历。
- 断网保存后恢复网络可同步。

### 审核合规

- 不鼓励冲动辞职。
- 不提供法律、医疗、心理治疗、职业咨询服务。
- 不展示用户生成公开内容。
- 隐私政策覆盖实际数据处理。

### 体验质量

- 页面无明显空白。
- 分享卡图片不裁切。
- 小屏手机文案不挤压。
- 真机无持续高频 setData 警告。

## 14. 暂不开发范围

以下能力先不进入近期开发：

- AI 聊天。
- 社区、评论、排行榜。
- 好友关系。
- 付费订阅。
- 职业咨询服务。
- 法律咨询服务。
- 心理治疗或诊断。
- iOS App。

原因：

- 当前产品还在验证记录和分享主链路。
- 这些能力会显著增加审核、隐私、安全和维护成本。
- 如果 MVP 数据不好，优先优化首页、复盘和分享，不应先做重功能。
