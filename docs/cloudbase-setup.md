# 微信云开发接入说明

当前代码已经预留云开发接入层。默认不填写环境 ID 时，小程序仍使用本地存储；填写环境 ID 后，正式数据会同步到云数据库。

## 1. 创建云开发环境

1. 用正式小程序 AppID 打开微信开发者工具。
2. 点击顶部“云开发”。
3. 创建环境，例如 `niuma-prod`。
4. 复制环境 ID。

## 2. 填写环境 ID

打开 `utils/cloud-config.js`：

```js
const CLOUD_CONFIG = {
  envId: '你的环境ID'
}
```

未填写时，云开发会保持关闭，所有功能仍然走本地存储。

## 3. 创建数据库集合

在云开发控制台创建集合：

- `daily_records`
- `user_settings`
- `wishes`
- `checklist_items`

## 4. 部署小程序码云函数

分享“指数卡”时会生成“卡片图片 + 小程序码”的海报。小程序码必须通过云端接口生成，项目里已经放好云函数：

```text
cloudfunctions/getAppCode/
```

在微信开发者工具中：

1. 右键 `cloudfunctions/getAppCode`。
2. 选择“上传并部署：云端安装依赖”。
3. 部署完成后，回到分享页点击“分享我的状态”。

如果没有部署这个云函数，分享页会提示“小程序码生成失败”，但赚钱卡的“保存这份坚持”仍然可以保存本地图片。

## 5. 权限建议

MVP 上线建议把集合权限设为“仅创建者可读写”。这样用户只能读写自己创建的数据，适合打卡、愿望、设置这种私密数据。

## 6. 当前同步策略

### 今日打卡

- 页面先读取本地数据，保证启动快、断网可用。
- 如果云开发已启用，会再拉取云端当天记录。
- 点击保存后，先写本地，再异步同步云端。
- 云同步失败时，本地记录仍保留。
- 草稿仍只保存在本地。

### 我的设置

- 页面先读取本地设置。
- 如果云开发已启用，会再拉取云端设置并覆盖本地缓存。
- 点击保存后，先写本地，再异步同步云端。

### 离开后愿望

- 页面先读取本地愿望。
- 如果云开发已启用，会再拉取云端愿望并覆盖本地缓存。
- 新增、编辑、删除愿望时，先写本地，再异步同步云端。
- 愿望编辑草稿仍只保存在本地。

### 离职准备清单

- 页面先读取本地清单。
- 如果云开发已启用，会再拉取云端清单，并按同一个本地 id 合并到本地默认清单里。
- 新增、勾选、删除事项时，先写本地，再异步同步云端。

## 7. 上线前检查

- `project.config.json` 使用真实 AppID。
- `utils/cloud-config.js` 已填写正式环境 ID。
- 云数据库集合已创建。
- `getAppCode` 云函数已上传并部署。
- 集合权限为仅创建者可读写。
- 隐私政策说明正式数据会同步到云端，草稿保存在本机。
