# 微信云开发接入说明

当前代码已经预留云开发接入层。默认不填写环境 ID 时，小程序仍使用本地存储；填写环境 ID 后，正式数据会同步到云数据库。

## 1. 创建云开发环境

1. 用正式小程序 AppID 打开微信开发者工具。
2. 点击顶部“云开发”。
3. 创建环境，例如 `niuma-prod`。
4. 复制环境 ID。

## 2. 填写环境 ID

打开 `utils/cloud-config.js`：

```js
const CLOUD_CONFIG = {
  envId: '你的环境ID'
}
```

未填写时，云开发会保持关闭，所有功能仍然走本地存储。

## 3. 创建数据库集合

在云开发控制台创建集合：

- `daily_records`：打卡记录。
- `user_settings`：个人设置与月薪。
- `wishes`：愿望清单。
- `checklist_items`：准备清单项。
- `app_codes`：小程序码缓存（用于优化分享海报生成速度）。

## 4. 部署云函数

本项目包含以下云函数，需在微信开发者工具中分别部署：

### getAppCode
分享“指数卡”时会生成“卡片图片 + 小程序码”的海报。小程序码必须通过云端接口生成。

### clearUserData
提供安全、彻底的云端数据清空能力。该函数在服务端执行，确保仅删除当前用户的数据。

### sendDailyReminder
负责定时筛选开启提醒的用户，并通过微信订阅消息接口发送推送。

**注意：** 云函数目录下的 `node_modules` 已通过 `.cloudignore` 忽略，请始终选择“云端安装依赖”进行部署，避免上传本地庞大的依赖包。

**部署步骤：**
1. 在微信开发者工具目录树中，找到 `cloudfunctions/` 文件夹。
2. 分别右键点击 `getAppCode`、`clearUserData` 和 `sendDailyReminder`。
3. 选择“上传并部署：云端安装依赖”。

## 5. 订阅消息配置

`sendDailyReminder` 正常工作需要额外的配置：

1. **微信公众平台配置**：
   - 登录 [微信公众平台](https://mp.weixin.qq.com/)。
   - 找到“订阅消息”菜单。
   - 添加模板，建议选择“打卡提醒”或类似的长期订阅模板（取决于类目权限）。
   - 记录 **模板 ID**，并将其填入 `utils/constants.js` 的 `DEFAULT_REMINDER_SETTINGS.templateId` 中。
   - 确保模板字段包含 `thing1`（提醒内容）和 `thing2`（备注/详情），或根据实际字段名修改云函数代码。

2. **云函数定时触发器**：
   - 在云开发控制台，进入 `sendDailyReminder` 的配置页面。
   - 开启“定时触发器”。
   - 配置触发周期为每分钟触发一次；`sendDailyReminder` 会按用户设置的 `HH:mm` 精确匹配，低于每分钟的触发频率会导致非触发时刻的提醒无法发送。
   - Cron 表达式示例（每分钟触发一次）：`0 * * * * * *`（以云开发控制台实际 Cron 语法为准）。

## 6. 权限建议

MVP 上线建议把集合权限设为“仅创建者可读写”。这样用户只能读写自己创建的数据，适合打卡、愿望、设置这种私密数据。

`app_codes` 集合也建议设为“仅创建者可读写”，虽然它是缓存性质，但这样最安全。

## 7. 当前同步策略

### 今日打卡
- 页面先读取本地数据，保证启动快、断网可用。
- 如果云开发已启用，会再拉取云端当天记录。
- 点击保存后，先写本地，再异步同步云端。
- 云同步失败时，本地记录仍保留。
- 草稿仍只保存在本地。

### 我的设置
- 页面先读取本地设置。
- 如果云开发已启用，会再拉取云端设置并按 `updatedAt` 时间戳合并。
- 点击保存后，先写本地，再异步同步云端。

### 离开后愿望
- 页面先读取本地愿望。
- 如果云开发已启用，会再拉取云端愿望并按 `id` + `updatedAt` 合并。
- 新增、编辑、删除愿望时，先写本地，再异步同步云端。
- 愿望编辑草稿仍只保存在本地。

### 离职准备清单
- 页面先读取本地清单。
- 如果云开发已启用，会再拉取云端清单，并按 `id` + `updatedAt` 合并到本地默认清单里。
- 新增、勾选、删除事项时，先写本地，再异步同步云端。

## 8. 上线前检查

- `project.config.json` 使用真实 AppID。
- `utils/cloud-config.js` 已填写正式环境 ID。
- 云数据库集合已创建（包括 `app_codes`）。
- 云函数 `getAppCode` 已上传并部署。
- 云函数 `clearUserData` 已上传并部署。
- 云函数 `sendDailyReminder` 已上传并部署。
- 订阅消息模板 ID 已替换 `utils/constants.js` 中的占位值。
- `sendDailyReminder` 已在云开发控制台配置每分钟定时触发器。
- 所有集合权限均为“仅创建者可读写”。
- 隐私政策说明正式数据会同步到云端，草稿保存在本机。
