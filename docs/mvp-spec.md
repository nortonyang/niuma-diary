# 留马 MVP 规划

## 1. MVP 目标

第一版目标不是做完整 App，而是验证这个问题：

> 职场人是否愿意持续记录“每天为什么想走”，并把结果分享给别人？

MVP 应优先做微信小程序，原因是微信分享链路短，适合验证情绪共鸣和传播。

## 2. MVP 一句话

每天 30 秒记录班味状态，看看自己为什么累、忍住赚了多少钱、离开后最想干什么。

## 3. MVP 成功标准

上线后先用小范围种子用户验证。

### 建议目标

- 100 个真实用户完成首次打卡。
- 首次打卡完成率超过 60%。
- 次日留存超过 25%。
- 7 日留存超过 15%。
- 分享图生成率超过 20%。
- “离开后想干的事”填写率超过 30%。

如果达不到这些数据，先优化产品入口、文案和分享图，不急着加 AI 或社区。

## 4. MVP 范围

## 4.1 必做功能

### 今日打卡

用户每天记录一次职场状态。

字段：

- 日期。
- 班味指数，0-100。
- 今日状态：
  - 还能忍
  - 有点烦
  - 很想走
  - 立刻想裸辞
- 想走原因，可多选：
  - 钱少
  - 加班
  - 老板
  - 同事
  - 客户
  - 通勤
  - 没成长
  - 被 PUA
  - 工作无意义
  - 身体吃不消
  - 其他
- 今日一句话吐槽，可选。

验收标准：

- 用户 30 秒内可完成一次打卡。
- 当天重复进入时展示已打卡状态。
- 用户可以修改当天记录。
- 没写吐槽也可以提交。

### 班味日历

用月历展示每天的班味指数。

字段和展示：

- 每天一个色块。
- 颜色按指数分级。
- 点击日期查看当天详情。
- 月度摘要展示：
  - 本月打卡天数
  - 本月平均班味指数
  - 本月最常见原因 Top 3
  - 本月最高班味指数

验收标准：

- 能查看当前月份。
- 能切换上个月和下个月。
- 未打卡日期显示为空。
- 已打卡日期能打开详情。

### 离开后想干的事

让用户记录最多 3 个离开后愿望。

字段：

- 标题。
- 分类：
  - 休息
  - 旅行
  - 学习
  - 副业
  - 转行
  - 创业
  - 陪家人
  - 什么都不干
  - 其他
- 预计花费，可选。
- 第一小步，可选。

验收标准：

- 用户最多可创建 3 个愿望。
- 愿望可编辑和删除。
- 首页展示一个重点愿望。
- 空状态提供示例引导。

### 忍一天赚多少钱

用户输入月薪后，计算每天和每小时大约收入。

字段：

- 月薪。
- 每月工作天数，默认 21.75。
- 每日工作小时，默认 8。

计算：

- 日收入 = 月薪 / 每月工作天数。
- 小时收入 = 日收入 / 每日工作小时。
- 本月已忍收入 = 日收入 * 本月已打卡天数。

验收标准：

- 用户可不填写月薪。
- 不填写月薪时隐藏收入相关展示。
- 月薪默认只保存在本地。
- 分享图默认不显示具体月薪。

### 分享图

生成适合微信传播的图片。

MVP 只做 2 类：

- 今日班味状态卡。
- 今日忍住赚钱卡。

卡片内容：

- 产品名：留马。
- 今日班味状态。
- 今日状态。
- 一句分享文案。
- 小程序码或引导文字。

验收标准：

- 用户可保存图片。
- 用户可转发给朋友或群聊。
- 默认不展示吐槽原文。
- 默认不展示月薪。

### 本地存储

MVP 不做账号系统，不做服务器。

本地数据包括：

- 每日打卡记录。
- 离开后愿望。
- 月薪设置。
- 基础偏好设置。

验收标准：

- 关闭小程序后再次打开，数据仍在。
- 提供清空本地数据入口。
- 隐私政策说明数据默认存储在用户设备本地。

## 4.2 可选功能

如果开发时间允许，可以加：

- 打卡提醒。
- 补记历史日期。
- 简单离职冷静器。
- 月度班味报告分享图。
- 自定义昵称。

## 4.3 明确不做

第一版不要做：

- 社区。
- 评论。
- 好友关系。
- 排行榜。
- AI 聊天。
- 云同步。
- 账号登录。
- 订阅付费。
- iOS App。
- 复杂任务系统。
- 职业咨询服务。

这些功能会拖慢验证，也会增加审核、合规和维护成本。

## 5. MVP 页面结构

底部 4 个 Tab：

- 今天
- 日历
- 愿望
- 我的

## 5.1 今天

核心入口。

模块顺序：

- 今日日期和一句随机文案。
- 班味指数滑杆。
- 今日状态选择。
- 想走原因多选。
- 一句话吐槽输入框。
- 保存打卡按钮。
- 忍一天赚多少钱卡片。
- 生成分享图按钮。

## 5.2 日历

展示历史记录。

模块顺序：

- 月份切换。
- 班味日历。
- 月度摘要。
- 当天详情弹窗或详情区。

## 5.3 愿望

记录离开后想干的事。

模块顺序：

- 顶部说明：“如果有一天离开这里，你最想先做什么？”
- 愿望列表，最多 3 个。
- 新增愿望按钮。
- 每个愿望展示分类、预计花费、第一小步。

## 5.4 我的

设置和隐私。

模块顺序：

- 昵称。
- 月薪设置。
- 工作天数设置。
- 每日工作小时设置。
- 清空本地数据。
- 隐私政策。
- 关于留马。

## 6. 数据结构建议

```ts
type QuitMood = 'ok' | 'annoyed' | 'want_quit' | 'explode'

type QuitReason =
  | 'low_salary'
  | 'overtime'
  | 'boss'
  | 'coworker'
  | 'client'
  | 'commute'
  | 'no_growth'
  | 'pua'
  | 'meaningless'
  | 'health'
  | 'other'

type DailyRecord = {
  date: string
  quitIndex: number
  mood: QuitMood
  reasons: QuitReason[]
  note?: string
  createdAt: number
  updatedAt: number
}

type WishCategory =
  | 'rest'
  | 'travel'
  | 'study'
  | 'side_project'
  | 'career_change'
  | 'startup'
  | 'family'
  | 'nothing'
  | 'other'

type AfterQuitWish = {
  id: string
  title: string
  category: WishCategory
  estimatedCost?: number
  firstStep?: string
  createdAt: number
  updatedAt: number
}

type UserSettings = {
  nickname?: string
  monthlySalary?: number
  workDaysPerMonth: number
  workHoursPerDay: number
}
```

## 8. 文案方向

## 8.1 产品主文案

- 每天都想走，但先记一下。
- 今日班味浓度检测。
- 今天没裸辞，也算一种胜利。
- 我不是在忍，我是在给退路攒预算。

## 8.2 空状态文案

- 还没有记录，今天的班味浓度是多少？
- 如果明天不上班，你最想先做什么？
- 写下第一件想做的事，不代表今天就要辞。

## 8.3 冷静表达

建议使用：

- 先记录，再决定。
- 先准备退路，再做选择。
- 今天情绪很满，明天再看一遍。

避免使用：

- 马上裸辞。
- 教你干翻老板。
- 不爽就走。
- 公司都该死。

## 9. 视觉方向

建议不要做成普通效率工具风格，可以偏“打工人自嘲 + 情绪日历”。

### 关键词

- 轻松。
- 自嘲。
- 温暖。
- 有一点荒诞感。
- 不压抑。

### 色彩建议

- 背景用米白或浅黄，减少医疗/心理 App 的严肃感。
- 高压状态用橙红色，但不要大面积血红。
- 低压状态用浅绿色或浅蓝色。
- 卡片可以有贴纸、便签、工牌、打卡机等元素。

## 10. 开发优先级

### 第 1 周

- 搭建小程序项目。
- 完成数据结构和本地存储。
- 完成今日打卡页面。
- 完成基础设置。

### 第 2 周

- 完成班味日历。
- 完成离开后愿望。
- 完成收入换算。
- 完成基础分享图。

### 第 3 周

- 完成隐私政策和关于页面。
- 优化文案和视觉。
- 真机测试。
- 提交审核。
- 邀请种子用户测试。

## 11. 测试清单

### 功能测试

- 首次打开无数据。
- 当天打卡保存成功。
- 当天重复打卡可编辑。
- 多选原因保存成功。
- 日历颜色正确。
- 月度统计正确。
- 愿望最多只能创建 3 个。
- 月薪为空时不展示收入。
- 清空数据后恢复初始状态。

### 兼容测试

- iPhone 微信。
- Android 微信。
- 小屏手机。
- 深色模式下可读。
- 断网可用。

### 审核测试

- App 名称和介绍不鼓励冲动辞职。
- 隐私政策可访问。
- 没有用户生成公开内容。
- 没有未经说明的个人信息收集。
- 分享图文案不过激。

## 12. 上线前必须准备

- 小程序名称。
- 小程序头像。
- 小程序简介。
- 隐私政策页面。
- 用户协议页面。
- 类目选择。
- 审核截图。
- 体验版测试二维码。
- 种子用户反馈表。

## 13. MVP 后的决策

根据数据决定下一步。

### 如果分享好、留存一般

优先优化：

- 分享图模板。
- 每日文案。
- 首次打卡体验。
- 微信群传播话术。

### 如果留存好、分享一般

优先优化：

- 月度报告。
- 打卡提醒。
- 愿望进度。
- 冷静器。

### 如果愿望填写率高

优先扩展：

- 愿望转计划。
- 预算计算。
- 离职准备清单。
- AI 拆解行动步骤。

### 如果用户只打卡不再回来

优先检查：

- 打卡是否太无聊。
- 日历是否缺少反馈。
- 有没有次日再来的理由。
- 分享图是否没有传播点。
